# Стандарты и шаблоны

Обязательные стандарты стиля кода, структуры модулей и шаблоны для всех проектов.

## Назначение

Стандарты созданы для:
- Единого стиля кода во всех проектах
- Быстрого старта при создании нового модуля
- Обеспечения качества кода
- Формирования узнаваемого стиля разработчика

## Главный документ

**[ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md](ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md)** - обязательный стандарт для всех проектов

Этот документ содержит:
- Обязательную структуру модуля
- Стандарты логирования
- Стандарты обработки ошибок
- Стандарты типизации
- Стандарты документации
- Шаблоны модулей и функций
- Чеклисты перед коммитом

**ВАЖНО:** При разработке любого кода всегда следуйте принципам из этого промпта.

## Принципы стандартов

### Принцип 1: Единообразие

Все проекты должны следовать единым стандартам:
- Одинаковая структура модулей
- Одинаковые подходы к логированию
- Одинаковые подходы к обработке ошибок

### Принцип 2: Явность

Явное лучше неявного:
- Явные константы вместо магических значений
- Явная типизация
- Явная обработка ошибок

### Принцип 3: Читаемость

Читаемость важнее всего:
- Понятные имена переменных и функций
- Подробная документация
- Логичная структура кода

### Принцип 4: Обработка ошибок

Ошибки не должны проходить молча:
- Все ошибки логируются
- Возвращаются безопасные значения по умолчанию
- Конкретные исключения для разных случаев

## Как использовать стандарты

### При создании нового модуля

1. Откройте [ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md](ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md)
2. Скопируйте шаблон модуля
3. Адаптируйте под свою задачу
4. Следуйте всем стандартам из промпта

### При проверке кода

Используйте чеклист из [ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md](ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md):
- [ ] Есть docstring модуля
- [ ] Импорты организованы правильно
- [ ] Все константы вынесены в начало
- [ ] Используется `_setup_logger()` для логирования
- [ ] Все функции имеют аннотации типов
- [ ] Все публичные функции имеют docstring
- [ ] Ошибки обрабатываются с логированием
- [ ] Используются константы вместо магических значений
