# Инструкции по разработке

Полная инструкция по разработке Python проектов.

## Назначение

Инструкция создана для:
- Единого процесса разработки во всех проектах
- Пошагового руководства при создании нового функционала
- Соблюдения правил и стандартов
- Обеспечения качества разработки

## Полная инструкция

### [ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md](ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md)

Единый документ, объединяющий:
- **Правила разработки** - приоритеты, правила комментариев, коммитов, важные принципы
- **Пошаговая инструкция разработки** - детальный процесс (ШАГ 1-10), примеры кода, Zen of Python
- **План разработки проекта** - стратегия, безопасность, этапы разработки, чеклисты

**Когда использовать:** При начале работы над новым проектом, написании кода и планировании разработки.

### Шаблон плана проекта

Шаблон для создания плана проекта:

- [шаблон-плана-проекта.md](../03-Стандарты-и-шаблоны/шаблоны-проектов/ШАБЛОН-ПЛАНА-ПРОЕКТА.md) - шаблон плана проекта
- Структура плана
- Декомпозиция задач
- Чеклисты

**Когда использовать:** При создании нового проекта.

## Как использовать инструкцию

### При начале нового проекта

1. Изучите [ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md](ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md) - раздел "План разработки проекта"
2. Используйте [шаблон-плана-проекта.md](../03-Стандарты-и-шаблоны/шаблоны-проектов/ШАБЛОН-ПЛАНА-ПРОЕКТА.md)
3. Следуйте правилам из раздела "Правила разработки"

### При написании кода

1. Следуйте [ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md](ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md) - раздел "Правила разработки"
2. Используйте пошаговую инструкцию из раздела "Пошаговая инструкция разработки"
3. Используйте приоритеты базы знаний
4. Следуйте стандартам из [03-Стандарты-и-шаблоны/](../03-Стандарты-и-шаблоны/)

### При планировании работы

1. Используйте [ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md](ПОЛНАЯ_ИНСТРУКЦИЯ_РАЗРАБОТКИ.md) - раздел "План разработки проекта"
2. Применяйте декомпозицию задач
3. Создавайте итеративные планы

## Приоритеты использования

### Приоритет 1: База знаний

База знаний имеет наивысший приоритет:
- Используйте подходы из [01-Учебные-материалы/](../01-Учебные-материалы/)
- Следуйте приоритетам: Приоритет 1 → Приоритет 2 → Приоритет 3

### Приоритет 2: Инструкции по разработке

Инструкции описывают конкретные шаги:
- Следуйте пошаговым инструкциям
- Используйте указанные подходы
- Соблюдайте структуру

### Приоритет 3: Стиль проекта

Если информации нет в базе знаний или инструкциях:
- Действуйте на свое усмотрение
- Сохраняйте подход и стиль написания кода

## Важные принципы

### Принцип 1: База знаний - наивысший приоритет

При написании кода всегда сначала проверяйте базу знаний:
- Используйте подходы из учебных материалов
- Следуйте стандартам из раздела стандартов
- Используйте примеры из раздела примеров

### Принцип 2: Следование инструкциям

Следуйте пошаговым инструкциям:
- Не пропускайте шаги
- Выполняйте проверки
- Соблюдайте чеклисты

### Принцип 3: Единый стиль

Все проекты должны следовать единому стилю:
- Используйте стандарты из [03-Стандарты-и-шаблоны/](../03-Стандарты-и-шаблоны/)
- Следуйте структуре модуля
- Используйте одинаковые подходы
