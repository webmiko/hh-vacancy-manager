## Основные концепции

### Типы ошибок

- **Синтаксические ошибки** - обнаруживаются до выполнения программы
- **Исключения** - возникают во время выполнения программы

### Обработка исключений

```python
try:
    # Код, который может вызвать исключение
    result = 10 / 0
except ZeroDivisionError:
    # Обработка конкретного исключения
    print("Деление на ноль невозможно")
except Exception as e:
    # Обработка всех остальных исключений
    print(f"Произошла ошибка: {e}")
else:
    # Выполняется, если исключений не было
    print("Операция выполнена успешно")
finally:
    # Выполняется всегда
    print("Завершение обработки")
```

### Вызов исключений

```python
# Вызов стандартного исключения
raise ValueError("Неверное значение")

# Вызов пользовательского исключения
class MyError(Exception):
    pass

raise MyError("Моя ошибка")

# Цепочка исключений
try:
    file = open("missing.txt")
except FileNotFoundError as e:
    raise ValueError("Ошибка обработки") from e
```

### Контекстные менеджеры

```python
# Автоматическое управление ресурсами
with open("file.txt") as f:
    content = f.read()
# Файл автоматически закроется
```

### Группы исключений (Python 3.11+)

```python
# Создание группы исключений
errors = [ValueError("1"), TypeError("2")]
raise ExceptionGroup("Проблемы", errors)

# Селективная обработка
try:
    process_data()
except* ValueError as eg:
    handle_value_errors(eg.exceptions)
except* TypeError as eg:
    handle_type_errors(eg.exceptions)
```
