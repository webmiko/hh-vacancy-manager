# Учебные материалы

Учебные материалы по Python, структурированные по областям применения с указанием приоритетов использования.

> **Источник:** База знаний создана на основе шпаргалок из папки `pre-code/dtbase`. Структурирована по областям применения с указанием приоритетов использования.

## 🎯 Приоритеты использования

- **Приоритет 1 (Обязательно)** - основы, без которых невозможно писать код
- **Приоритет 2 (Важно)** - необходимые инструменты для качественного кода
- **Приоритет 3 (По необходимости)** - продвинутые темы и инструменты

## 📚 Структура материалов

### 1. Основы Python (Приоритет 1)

Базовые концепции, которые нужно знать в первую очередь:

- [Строки](01-Основы/Строки.md) - работа со строками
- [Циклы](01-Основы/Циклы.md) - циклы for и while
- [Списки](02-Структуры-данных/Списки.md) - базовые коллекции данных

**Когда использовать:** Всегда, при написании любого кода.

---

### 2. Структуры данных (Приоритет 1)

Коллекции данных для хранения и обработки информации:

- [Списки](02-Структуры-данных/Списки.md) - упорядоченные коллекции
- [Словари](02-Структуры-данных/Словари.md) - пары ключ-значение
- [Множества, кортежи и вложенные коллекции](02-Структуры-данных/Множества-кортежи.md) - дополнительные типы коллекций

**Когда использовать:** При работе с данными любого типа.

---

### 3. Функции (Приоритет 1-2)

Организация кода в переиспользуемые блоки:

- [Базовые функции](03-Функции/Базовые-функции.md) - создание и использование функций
- [Продвинутые функции](03-Функции/Продвинутые-функции.md) - *args, **kwargs, lambda
- [Декораторы](03-Функции/Декораторы.md) - расширение функциональности функций

**Когда использовать:**
- Базовые функции - всегда
- Продвинутые функции - при необходимости гибкости
- Декораторы - для логирования, кэширования, валидации

---

### 4. Генераторы и включения (Приоритет 2)

Эффективная работа с данными:

- [Включения и генераторы](04-Генераторы/Включения-генераторы.md) - list/dict/set comprehensions и генераторы

**Когда использовать:**
- Включения - для создания коллекций из других коллекций
- Генераторы - для работы с большими объемами данных без загрузки в память

---

### 5. Модули и пакеты (Приоритет 2)

Организация кода в проектах:

- [Модули и пакеты](05-Модули/Модули-пакеты.md) - создание и импорт модулей

**Когда использовать:** При создании проектов с несколькими файлами.

---

### 6. Работа с данными (Приоритет 2-3)

Библиотеки для работы с различными форматами данных:

- [JSON, requests и datetime](06-Данные/JSON-requests-datetime.md) - работа с API и датами
- [CSV и pandas](06-Данные/CSV-pandas.md) - работа с табличными данными

**Когда использовать:**
- JSON, requests, datetime - при работе с API и обработке дат
- CSV, pandas - при анализе больших объемов табличных данных

---

### 7. Логирование (Приоритет 2)

Отслеживание работы программы:

- [Библиотека logging](07-Логирование/Logging.md) - настройка и использование логирования

**Когда использовать:** Для отладки и мониторинга работы приложения.

---

### 8. Тестирование (Приоритет 3)

Проверка корректности кода:

- [Тестирование с pytest](08-Тестирование/Pytest.md) - написание и запуск тестов

**Когда использовать:** Для обеспечения качества и надежности кода.

---

### 9. Инструменты разработки (Приоритет 3)

Инструменты для управления проектами и версиями:

- [Основы Git](09-Инструменты/Git-основы.md) - базовые команды Git
- [Продвинутый Git](09-Инструменты/Git-продвинутый.md) - ветвление, слияние, конфликты
- [Poetry. Оформление кода](09-Инструменты/Poetry-оформление.md) - управление зависимостями и форматирование

**Когда использовать:**
- Git - при работе в команде или для версионирования
- Poetry - для управления зависимостями в проектах

---

### 10. ООП (Объектно-ориентированное программирование) (Приоритет 2)

Создание классов и объектов для организации кода:

- [Классы и объекты](10-ООП/Классы-и-объекты.md) - создание классов, методы, атрибуты, наследование, полиморфизм
- [Режимы доступа](10-ООП/Режимы-доступа.md) - публичные, защищенные и приватные атрибуты и методы
- [Методы классов](10-ООП/Методы-классов.md) - classmethod и staticmethod, типы методов в классах
- [Property и свойства](10-ООП/Property-и-свойства.md) - декоратор @property, геттеры, сеттеры, делитеры

**Когда использовать:**
- При создании сложных программ с множеством связанных данных и функций
- Когда нужно логически группировать данные и методы
- Для создания собственных типов данных
- Для улучшения читаемости и модульности кода
- Когда нужно контролировать доступ к атрибутам класса
- Когда нужно создавать вычисляемые свойства

---

### 11. Декомпозиция задач (Приоритет 1)

Методология разбиения сложных задач на управляемые части:

- [Декомпозиция задач](11-Декомпозиция/Декомпозиция-задач.md) - процесс разбиения сложных задач, этапы декомпозиции, примеры

**Когда использовать:**
- При работе со сложными задачами, которые кажутся невыполнимыми
- Когда непонятно, с чего начать решение задачи
- Для планирования работы над проектом
- При разбиении большой задачи на управляемые части

---

### 12. Исключения (Приоритет 2)

Обработка ошибок выполнения программы:

- [Блоки try/except](12-Исключения/Блоки-try-except.md) - обработка исключений, типы исключений, блоки try/except/else/finally, иерархия исключений
- [Распространение исключений](12-Исключения/Распространение-исключений.md) - traceback, стек вызовов, распространение исключений по стеку, обработка на разных уровнях
- [Пользовательские исключения и raise](12-Исключения/Пользовательские-исключения-и-raise.md) - инструкция raise, создание пользовательских классов исключений, иерархия исключений
- [Тестирование исключений](12-Исключения/Тестирование-исключений.md) - pytest.raises(), проверка возникновения исключений, проверка сообщений исключений

**Когда использовать:**
- При работе с файлами, сетью, пользовательским вводом
- Когда нужно обработать возможные ошибки выполнения
- Для создания надежных программ, которые не падают при ошибках
- При работе с внешними ресурсами (API, базы данных, файлы)
- Для отладки и понимания, где именно возникла ошибка в цепочке вызовов

## 🗺️ Навигация по задачам

### Начинаю новый проект
1. Декомпозиция задач (разбить задачу на части)
2. Основы Python (строки, циклы)
3. Структуры данных (списки, словари)
4. Базовые функции
5. Модули и пакеты

### Работаю с данными
1. Структуры данных
2. JSON, requests, datetime
3. CSV, pandas (если нужен анализ таблиц)
4. Генераторы (для больших объемов)

### Нужна отладка
1. Логирование
2. Исключения (обработка ошибок)
3. Тестирование с pytest

### Работаю в команде
1. Git (основы)
2. Poetry (оформление кода)
3. Git (продвинутый)

### Создаю сложную структуру кода
1. Декомпозиция задач (разбить задачу на части)
2. Классы и объекты (ООП)
3. Режимы доступа (защита атрибутов)
4. Property и свойства (управление доступом)
5. Модули и пакеты
6. Исключения (обработка ошибок)
7. Тестирование с pytest

## Как использовать

1. Определите задачу
2. Найдите соответствующий раздел
3. Изучите материал согласно приоритету
4. Примените в своем проекте
5. Посмотрите примеры в [02-Примеры-кода/](../02-Примеры-кода/)
