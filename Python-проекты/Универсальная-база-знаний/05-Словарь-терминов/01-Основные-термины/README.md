# Основные термины Python

Словарь основных понятий и терминов Python с описанием, где используется и какую функцию выполняет.

## Структура

Термины организованы по категориям:
- [ООП термины](ООП-термины.md) - класс, объект, экземпляр, наследование и т.д.
- [Структурные термины](Структурные-термины.md) - модуль, пакет, функция, метод
- [Типы и данные](Типы-и-данные.md) - атрибут, свойство, переменная, константа
- [Исключения и ошибки](Исключения-и-ошибки.md) - исключения, обработка ошибок, try/except, raise и т.д.

## Как использовать

1. Найдите нужный термин в соответствующем файле
2. Изучите описание и примеры
3. Перейдите по ссылкам на связанные термины
4. Посмотрите примеры использования в [02-Примеры-кода/](../../02-Примеры-кода/)
