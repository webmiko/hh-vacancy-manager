# Встроенные функции Python

Словарь встроенных функций Python с описанием, где используется и какую функцию выполняет.

## Категории функций

- [Функции преобразования типов](Преобразование-типов.md) - str(), int(), float(), list(), dict() и т.д.
- [Функции работы с коллекциями](Работа-с-коллекциями.md) - len(), range(), enumerate(), zip(), map(), filter()
- [Функции работы со строками](Работа-со-строками.md) - sorted(), reversed(), min(), max(), sum()
- [Функции ввода-вывода](Ввод-вывод.md) - print(), input(), open()

## Как использовать

1. Найдите нужную функцию в соответствующем файле
2. Изучите описание, параметры и возвращаемое значение
3. Посмотрите примеры использования
4. Перейдите по ссылкам на связанные функции
