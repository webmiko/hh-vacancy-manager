# Словарь терминов и выражений

Справочник значений, выражений, функций и терминов Python с описанием, где используется и какую функцию выполняет.

## Назначение

Словарь создан для:
- Быстрого поиска значений и выражений
- Понимания назначения функций и операторов
- Определения, где и когда использовать тот или иной термин
- Справочной информации при написании кода

- Атрибут, свойство
- И другие базовые термины

## Как использовать словарь

### Поиск термина

1. Определите категорию термина
2. Откройте соответствующий раздел
3. Найдите термин в алфавитном порядке или по категориям
4. Изучите описание, примеры использования и связанные термины

### Структура записи термина

Каждый термин содержит:
- **Название** - термин или выражение
- **Описание** - что это такое
- **Где используется** - в каких ситуациях применяется
- **Какую функцию выполняет** - назначение и результат
- **Примеры** - примеры использования
- **Связанные термины** - ссылки на связанные понятия
