# Market Place - Пример проекта интернет-магазина

Этот пример содержит код проекта интернет-магазина (Market Place), демонстрирующий использование ООП в Python.

## Структура проекта

- `src/` - исходный код приложения
  - `category.py` - класс Category для работы с категориями товаров, абстрактный класс BaseEntity
  - `product.py` - классы Product, Smartphone, LawnGrass для работы с товарами, абстрактный класс BaseProduct, миксин LogCreationMixin
  - `data_loader.py` - модуль для загрузки данных из JSON файлов
  - `order.py` - класс Order для работы с заказами

- `tests/` - тесты для всех модулей
  - `conftest.py` - общие фикстуры для тестов
  - `test_category.py` - тесты для класса Category
  - `test_product.py` - тесты для классов Product, Smartphone, LawnGrass
  - `test_data_loader.py` - тесты для модуля загрузки данных
  - `test_order.py` - тесты для класса Order

## Основные концепции

### ООП концепции

1. **Классы и объекты**
   - Базовый класс `Product` для представления товара
   - Наследование: `Smartphone` и `LawnGrass` наследуются от `Product`
   - Инкапсуляция: использование приватных атрибутов (`__products`, `__price`)
   - Полиморфизм: переопределение методов `__eq__`, `__str__`, `__add__`

2. **Абстрактные классы**
   - `BaseEntity` - абстрактный базовый класс для сущностей с названием и описанием (Category, Order)
   - `BaseProduct` - абстрактный базовый класс для всех продуктов
   - Использование `ABC` и `@abstractmethod` для определения интерфейсов

3. **Property декоратор**
   - Использование `@property` для `price` с геттером и сеттером
   - Валидация данных при установке цены
   - Защита от некорректных значений

4. **Миксины**
   - `LogCreationMixin` - миксин для логирования создания объектов
   - Использование множественного наследования

5. **Магические методы**
   - `__init__` - инициализация объектов
   - `__str__` - строковое представление
   - `__add__` - сложение объектов (с проверкой типов)
   - `__eq__` - сравнение объектов
   - `__iter__` - итерация по продуктам в категории

6. **Класс-методы**
   - `new_product` - альтернативный конструктор для создания продукта из словаря

### Работа с данными

1. **Загрузка из JSON**
   - Парсинг JSON файлов
   - Валидация данных
   - Обработка ошибок

2. **Логирование**
   - Настройка логгеров для каждого модуля
   - Запись в файлы
   - Защита конфиденциальных данных при логировании

### Тестирование

1. **Pytest**
   - Использование фикстур
   - Параметризация тестов
   - Моки и патчи

2. **Покрытие тестами**
   - Тесты для всех классов и методов
   - Тесты граничных случаев
   - Интеграционные тесты

## Примеры использования

### Создание продукта

```python
from src.product import Product

product = Product(
    name="Samsung Galaxy S23 Ultra",
    description="256GB, Серый цвет, 200MP камера",
    price=180000.0,
    quantity=5
)
```

### Создание категории

```python
from src.category import Category
from src.product import Product

product1 = Product("Product 1", "Description 1", 100.0, 5)
product2 = Product("Product 2", "Description 2", 200.0, 10)

category = Category(
    name="Смартфоны",
    description="Смартфоны для коммуникации",
    products=[product1, product2]
)
```

### Наследование

```python
from src.product import Smartphone, LawnGrass

smartphone = Smartphone(
    name="Samsung Galaxy S23 Ultra",
    description="256GB, Серый цвет, 200MP камера",
    price=180000.0,
    quantity=5,
    efficiency=95.5,
    model="S23 Ultra",
    memory=256,
    color="Серый"
)

grass = LawnGrass(
    name="Газонная трава",
    description="Элитная трава для газона",
    price=500.0,
    quantity=20,
    country="Россия",
    germination_period="7 дней",
    color="Зеленый"
)
```

### Загрузка данных из JSON

```python
from src.data_loader import load_categories_from_json

categories = load_categories_from_json("data/products.json")
```

### Создание заказа

```python
from src.order import Order
from src.product import Product

product = Product("Test Product", "Description", 100.0, 10)
order = Order("ORD-001", "Тестовый заказ", product, 5)

print(order)
# Заказ ORD-001: Test Product, количество: 5, итого: 500.0 руб.
```

## Особенности реализации

1. **Валидация данных** - проверка типов и значений при создании объектов
2. **Защита от изменений** - копирование списков для предотвращения побочных эффектов
3. **Обработка ошибок** - корректная обработка исключений с логированием
4. **Типизация** - использование type hints для улучшения читаемости кода
5. **Документация** - подробные docstrings для всех классов и методов
6. **Абстрактные классы** - использование ABC для определения интерфейсов и обеспечения полиморфизма
7. **Миксины** - использование множественного наследования для переиспользования функциональности
8. **Работа с заказами** - класс Order для представления заказов с расчетом итоговой стоимости
