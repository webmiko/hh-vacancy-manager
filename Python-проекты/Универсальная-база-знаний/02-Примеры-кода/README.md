# Примеры кода и банк кода

Эталонные примеры кода и банк кода для переиспользования во всех проектах. Все примеры следуют стандартам из [03-Стандарты-и-шаблоны/](../03-Стандарты-и-шаблоны/).

> **📝 Примечание:** Банк кода (ранее `bank-code/`) теперь объединен с примерами кода и организован тематически.

## Назначение

Примеры кода и банк кода созданы для:
- Быстрого старта при создании нового модуля
- Изучения правильных паттернов и подходов
- Переиспользования проверенных решений
- Формирования единого стиля кода
- Использования готовых модулей в проектах
- **Удобной работы с искусственным интеллектом** - каждый файл содержит метаданные, отсылки и пояснения

## Структура примеров

Примеры кода организованы по тематическим категориям для удобной навигации.

### 📁 Работа с файлами (`работа-с-файлами/`)

  - Связанные модули: `ооп/oop_classes.py`, `ооп/advanced_oop.py`, `работа-с-файлами/data_loading.py`
  - Учебные материалы:
    - [JSON-requests-datetime.md](../01-Учебные-материалы/06-Данные/JSON-requests-datetime.md)

    - Защита конфиденциальных данных при логировании
    - Валидация данных перед созданием объектов

## Как использовать примеры

### Шаг 1: Найдите подходящий пример

Определите категорию и найдите похожий пример в соответствующей папке. Каждый файл содержит в начале:
- Категорию
- Связанные модули
- Учебные материалы
- Когда использовать

### Шаг 2: Изучите структуру

Обратите внимание на:
- Структуру модуля (docstring, импорты, константы, функции)
- Логирование (настройка логгера)
- Обработку ошибок
- Типизацию
- Документацию
- Метаданные в начале файла (категория, связанные модули, учебные материалы)

### Шаг 3: Скопируйте и адаптируйте

1. Скопируйте структуру модуля
2. Адаптируйте под свою задачу
3. Сохраните общие принципы (логирование, обработка ошибок, типизация)
4. Обновите метаданные в начале файла

### Шаг 4: Следуйте стандартам

Убедитесь, что код следует стандартам из [03-Стандарты-и-шаблоны/](../03-Стандарты-и-шаблоны/).

## Принципы использования

### Принцип 1: Структура модуля

Все примеры следуют единой структуре:
```
Docstring → Импорты → Константы → Приватные функции → Логгер → Публичные функции
```

### Принцип 2: Логирование

Примеры показывают правильную настройку логирования:
- Приватная функция `_setup_logger()`
- Логи в папке `logs/`
- Детальные сообщения с типом ошибки

### Принцип 3: Обработка ошибок

Примеры демонстрируют правильную обработку ошибок:
- Возврат безопасных значений по умолчанию
- Детальное логирование: `{type(e).__name__} - {e}`
- Конкретные исключения для разных случаев

### Принцип 4: Документация

Все примеры имеют подробную документацию:
- Docstrings с Args, Returns, Raises, Examples
- Комментарии для сложной логики
- Метаданные в начале файла (категория, связанные модули, учебные материалы)

### Принцип 5: Типизация

Все примеры используют типизацию:
- Аннотации типов для всех функций
- Явная типизация для сложных переменных

### Принцип 6: Метаданные для ИИ

Каждый файл содержит метаданные в начале:
- Категория модуля
- Связанные модули
- Учебные материалы
- Когда использовать

Это позволяет искусственному интеллекту лучше понимать контекст и находить связанные примеры.
