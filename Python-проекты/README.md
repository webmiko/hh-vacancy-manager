# Python-проекты

База знаний, промпты и инструкции для разработки проектов на Python.

## 📁 Структура

```
Python-проекты/
├── bank-code/                    # База кода и стандарты стиля
│   ├── ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md   # Обязательный промпт для всех Python проектов
│   └── [модули Python]          # Примеры кода и утилиты
│
└── Универсальная-база-знаний/   # Универсальная база знаний по Python
    ├── 01-Учебные-материалы/     # Учебные материалы
    ├── 02-Примеры-кода/         # Примеры кода
    ├── 03-Стандарты-и-шаблоны/  # Стандарты и шаблоны
    ├── 04-Инструкции-разработки/# Инструкции по разработке
    └── 05-Словарь-терминов/      # Словарь терминов
```

## 🎯 Назначение

Эта папка содержит все материалы для разработки проектов на Python:
- **bank-code** - обязательные стандарты стиля кода
- **Универсальная-база-знаний** - учебные материалы, примеры и инструкции

## 📖 Как использовать

### Для новых Python проектов:

1. **Изучите стандарты:**
   - `Универсальная-база-знаний/03-Стандарты-и-шаблоны/ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md` - обязательный стандарт стиля

2. **Используйте базу знаний:**
   - `Универсальная-база-знаний/01-Учебные-материалы/` - учебные материалы
   - `Универсальная-база-знаний/02-Примеры-кода/` - примеры кода и банк кода (тематически организован)
   - `Универсальная-база-знаний/03-Стандарты-и-шаблоны/` - стандарты и шаблоны

3. **Следуйте инструкциям:**
   - `Универсальная-база-знаний/04-Инструкции-разработки/` - пошаговые инструкции

## ⚠️ Важно

- **Универсальная-база-знаний/03-Стандарты-и-шаблоны/ПРОМПТ-ДЛЯ-ПРОЕКТОВ.md** - это ОБЯЗАТЕЛЬНЫЙ стандарт для всех Python проектов
- Всегда следуйте принципам из этого промпта при написании кода
- Используйте примеры из `02-Примеры-кода/` как основу для своего кода
