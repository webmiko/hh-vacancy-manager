# HH Vacancy Manager

Программа для получения информации о вакансиях с платформы hh.ru в России, сохранения ее в файл и удобной работы с ней: добавления, фильтрации, удаления.

## Описание проекта

HH Vacancy Manager — это консольное приложение для работы с вакансиями с платформы hh.ru. Программа позволяет:

- 🔍 Получать вакансии по ключевому слову через API hh.ru (только по России, зарплаты в рублях)
- 💾 Сохранять вакансии в JSON-файл
- 🔎 Фильтровать вакансии по ключевым словам
- 📊 Сортировать вакансии по зарплате
- 📈 Получать топ N вакансий по зарплате
- 🗑️ Удалять вакансии из файла

## Особенности

- ✅ Работа только с вакансиями из России (area=113)
- ✅ Фильтрация по валюте RUR (рубли)
- ✅ Предотвращение дублирования вакансий при сохранении
- ✅ Полная типизация кода
- ✅ Покрытие тестами более 95%
- ✅ Соответствие принципам Zen of Python
- ✅ Обработка ошибок с логированием
- ✅ Проверка безопасности (защита от утечки конфиденциальных данных)

## Установка

### Требования

- Python 3.10 или выше
- Poetry (менеджер зависимостей)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd hh-vacancy-manager
```

2. Установите зависимости:
```bash
poetry install
```

3. Активируйте виртуальное окружение:
```bash
poetry shell
```

4. (Опционально) Настройте переменные окружения:
```bash
# Скопируйте шаблон .env.example в .env
cp .env.example .env

# Отредактируйте .env и добавьте свои значения (если требуется)
# Для работы с hh.ru API ключ обычно не требуется
```

## Использование

### Запуск программы

Основной способ запуска:
```bash
poetry run python main.py
```

Альтернативные способы:
```bash
# Через модуль
poetry run python -m src.user_interface

# Прямой запуск модуля
poetry run python src/user_interface.py
```

### Пример работы

1. При запуске программа запросит поисковый запрос:
```
Введите поисковый запрос для запроса вакансий из hh.ru: Python
```

2. Программа получит вакансии из API hh.ru (только по России, с зарплатой в рублях)

3. Вакансии будут автоматически сохранены в файл `data/vacancies.json`

4. Затем программа запросит количество вакансий для топа:
```
Введите количество вакансий для вывода в топ N: 10
```

5. Можно указать ключевые слова для фильтрации:
```
Введите ключевые слова для фильтрации вакансий (через пробел): Django Flask
```

6. Программа выведет топ N вакансий, отсортированных по зарплате

## API hh.ru

### Особенности работы с API

- **Регион**: Поиск только по России (area=113)
- **Валюта**: Фильтрация по валюте RUR (рубли)
- **Пагинация**: Автоматическая обработка до 20 страниц
- **Обработка ошибок**: Все ошибки логируются и обрабатываются явно

### Ограничения API

- Максимум 20 страниц результатов (2000 вакансий при 100 на странице)
