# HH Vacancy Manager

Программа для получения информации о вакансиях с платформы hh.ru в России, сохранения ее в файл и удобной работы с ней: добавления, фильтрации, удаления.

## Описание проекта

Проект предназначен для работы с API hh.ru и управления данными о вакансиях.

## Установка

1. Создайте виртуальное окружение:
```bash
poetry install
```

2. Активируйте виртуальное окружение:
```bash
poetry shell
```

_Инструкции будут добавлены после реализации функционала_
